# Repository notice

NanoFiles was developed for the Computer Networks course at the University of Murcia.

The course supplied a Java scaffold containing application entry points, the command shell, utility classes, interfaces, class skeletons, and TODO specifications. Original author annotations in scaffolded files have been preserved.

Jorge Muñoz Ibañez independently designed the four application-layer protocol state machines and implemented all required and optional networking functionality, including:

- reliable UDP request-response communication;
- text and binary message serialization;
- peer registration and discovery;
- concurrent TCP file serving;
- complete-file and chunk-based transfers;
- parallel downloads from multiple peers; and
- reconstruction and SHA-1 integrity verification.

This cleaned copy is provided as a code sample. It excludes course handouts, compiled artifacts, and generated test data. No open-source license is granted for scaffolded course material.
